Vue 核心语法：从模板指令到组合式 API

发表于2026-10-21|更新于2026-10-21|技术
|浏览量:

Vue 系列第一篇。按”模板 → 数据”两层重新组织了一遍：Vue3 组合式 API 唱主角，Vue2 选项式只留对照，两代语法互相定位。学完你会知道：六大类指令和修饰符怎么用、ref 和 reactive 怎么选、computed 的缓存到底缓存了什么、watch 的 immediate 和 deep 什么时候开、两代生命周期钩子怎么一一对应。文末附四张速查表。

一、先给地图：两种 API 风格

Vue3 最大的变化不是新功能，是写法。同一个计数器，两种写法摆在一起看最直观。

Vue2 选项式：

Vue3 组合式：

区别就两点：

  1. 代码量变少：不用 data、methods 一层层包着，直接声明变量和函数
  2. 分散式维护变成集中式维护：Vue2 里一个功能的 data、methods、computed 散落在各个选项；Vue3 里按功能聚在一起，一个功能的所有代码挨着写

怎么选，一句话：

  • 新项目：无脑组合式，配 <script setup> 语法糖
  • 读旧项目：必须认识选项式，公司里一堆 Vue2 代码还得维护

这篇的写法：每个知识点，Vue3 写法在前，Vue2 写法标注对照。通用内容（指令、修饰符这些模板层的）两代完全一样，不重复讲。

二、模板语法：六大类指令

指令是 Vue 提供的带 v- 前缀的特殊标签属性，作用是提高操作 DOM 的效率。按用途分六大类：

分类 指令 一句话
内容渲染 v-text、v-html 把数据渲染成文本/HTML
条件渲染 v-show、v-if、v-else、v-else-if 控制显示隐藏
事件绑定 v-on（简写 @） 注册事件
属性绑定 v-bind（简写 :） 动态设置标签属性
双向绑定 v-model 表单元素专用
列表渲染 v-for 循环渲染

这套指令 Vue2、Vue3 完全通用，是复习的压舱石。

2.1 内容渲染：v-text 和 v-html

  • v-text 类似 innerText，纯文本输出
  • v-html 类似 innerHTML，能渲染 HTML 标签

⚠️ v-html 是 XSS 重灾区，永远不要把它用在用户输入的内容上。只在内容完全可信时用。

2.2 条件渲染：v-show 和 v-if

都在控制显示隐藏，底层完全不同：

v-show v-if
原理 切换 display: none 真正创建/移除 DOM 节点
场景 频繁切换 不频繁切换
开销 一次渲染，后续只切样式 每次切换都要重新创建/销毁

配合 v-else、v-else-if 做多路判断，v-else 必须紧挨 v-if，中间夹任何东西都不生效。

2.3 事件绑定：@ 的三种写法

两个容易忘的点：

  • 不传参时，方法里可以直接用 e 当事件对象（Vue 会自动把事件对象作为第一个参数传进去）
  • 传了参数，事件对象必须用 $event 占位，@click="buy(5, $event)"

2.6 双向绑定：v-model

双向的意思是：数据变 → 视图更新；视图变（输入）→ 数据同步。只给表单元素用（input、radio、select、textarea、checkbox），非表单元素上用它没意义。

v-model 在自定义组件上的用法两代差异很大，放第二篇组件篇讲。

三、修饰符：少写代码的偷懒神器

修饰符是跟在指令后面的“小尾巴”，用 . 开头，把常见逻辑压缩成一个词。

3.1 事件修饰符

修饰符 作用
.prevent 阻止默认行为（相当于 e.preventDefault()）
.stop 阻止冒泡
.self 只有点元素自己才触发
.once 只触发一次
.capture 捕获阶段触发

3.2 按键修饰符

常用别名：.enter、.esc、.tab、.delete、.space、.up、.down、.left、.right，系统修饰键 .ctrl、.alt、.shift、.meta。

⚠️ 版本差异：Vue2 支持用键码写按键修饰符（如 @keyup.13），Vue3 把这个支持移除了，只能写别名。老代码里见到 .13 这种写法，知道是键码就行。

3.3 v-model 修饰符

三个都好记：.number 转数字、.trim 去空格、.lazy 延迟同步。三个在两代里通用。

四、class 和 style 绑定

给标签动态加类名和样式，是 tab 高亮、进度条这类需求的基本功。用 v-bind 的特殊语法。

4.1 对象语法

对象里可以写多个类，值可以是任何真值表达式。

4.2 数组语法

数组里放类名，可以混三元表达式。京东秒杀那个 tab 栏切换高亮，就是判断当前下标和遍历下标是否相等来动态加类，用这套语法十几行搞定。

style 同理，:style="{ color: textColor, fontSize: size + 'px' }"，进度条案例靠它动态改宽度。

5.1 Vue2：都放 data 里

5.3 ref vs reactive 对照

ref reactive
支持类型 基本类型 + 对象 仅对象
访问方式 模板自动解包，script 里 .value 直接访问
实现关系 ref 内部靠 reactive 实现 ——

工作推荐：默认用 ref。 理由就一条——不用每次多写 .value 的判断，减少记忆负担。教程里的项目也基本全用 ref。

5.4 ⚠️ reactive 解构会丢响应性

解构出来的是那一刻的值快照，跟响应式对象脱钩了。注意这不是 reactive 独有的坑——ref 里的对象解构一样脱钩。要么整体访问，要么用 toRefs 把属性一个个转成 ref 再解构。

6.2 computed vs methods：差一个缓存

小黑的礼物清单求总数，用 computed 和 methods 都能实现，差别在性能：

  • computed 有缓存：依赖不变，重复访问直接读缓存，不重算；依赖变了才重新计算并再缓存
  • methods 没缓存：每次调用都实打实执行一遍

结论：

  • 一个结果依赖其他数据算出来 → computed
  • 处理业务逻辑（事件处理函数）→ methods

⚠️ computed 计算属性不能和 data 里的属性同名，同名会冲突报错。

七、watch：数据变了就通知你

computed 是“被动重算”，watch 是“主动通知”——数据变了，执行你指定的回调，适合副作用（请求、打印、动 DOM）。

7.2 immediate 和 deep

两个配置项，Vue2 的 watch 选项里也支持，Vue3 放第三个参数对象里：

  • immediate：刚进页面就想拿到初始数据去请求，用它，省得手动先调一次
  • deep：监听对象内部深层属性的变化

7.3 ⚠️ 一个反直觉的点：ref 对象默认浅侦听

直接改 state.value.count，回调不执行——因为 watch 一个 ref 默认是浅层侦听，只盯 ref 本身被换掉。要盯深层属性，加 deep: true。

反过来记一条：watch 一个 reactive 对象，默认就是深度侦听。两个默认值相反，是经典易错点。

八、生命周期：两代钩子对照

8.1 四阶段

一个实例从生到死分四步：创建 → 挂载 → 更新 → 销毁。每个阶段开头结尾有钩子函数，让开发者把代码插进特定时机。

  • 创建阶段：准备响应式数据
  • 挂载阶段：渲染模板
  • 更新阶段：数据变 → 视图更新
  • 销毁阶段：清理实例

8.2 对照表

Vue2 选项式 Vue3 组合式 时机
beforeCreate ——（用 setup 代替） 实例创建前
created ——（setup 本身） 数据已准备好，DOM 未渲染
beforeMount onBeforeMount 挂载前
mounted onMounted DOM 渲染完成
beforeUpdate onBeforeUpdate 数据变、视图更新前
updated onUpdated 视图更新完成
beforeDestroy onBeforeUnmount 销毁前
destroyed onUnmounted 销毁完成

记法：两代钩子一一对应，Vue3 统一加 on 前缀；Vue2 的 created 没有单独对应物，因为 <script setup> 本身就是“创建后、挂载前”执行的代码。

8.3 两个最常用的场景

  • 发初始化请求：created（Vue2）或直接写在 setup 里（Vue3），越早发越好
  • 操作 DOM / 获取焦点：mounted（onMounted），这时 DOM 才真渲染出来。记账清单案例里输入框自动聚焦就用的它

Vue3 里生命周期函数可以执行多次，按书写顺序依次执行，组合式下拆分逻辑更自由。

九、速查表

9.1 指令速查

指令 作用 易错点
v-text / v-html 渲染文本/HTML 会覆盖标签原内容；v-html 防 XSS
v-show display 切换显隐 频繁切换用它
v-if / v-else 条件渲染 不频繁切换用它；else 紧挨 if
@ / v-on 事件绑定 传参时用 $event 拿事件对象
: / v-bind 属性绑定 class/style 用对象/数组语法
v-model 表单双向绑定 只用于表单元素
v-for 列表渲染 key 用 id 不用 index

9.2 ref vs reactive

ref reactive
基本类型 ✅ ❌
对象 ✅（.value） ✅
对象解构 同样丢响应性 丢响应性
日常推荐 默认用它 大对象整体管理时用

9.3 watch 配置项

配置 作用 典型场景
immediate 创建时立即执行回调 进页面就发请求
deep 深度侦听对象属性 监听 ref 里的对象变化

Vue2 Vue3
created setup 内直接写

总结

这篇复习下来，主线就五条：

  1. API 风格：新项目组合式 + <script setup>，旧项目选项式，两边都要认识
  2. 指令是压舱石：六大类两代通用，v-show/v-sif 的分界、v-for 的 key、v-model 的范围是高频考点
  3. 数据层换代：data → ref/reactive，默认 ref，reactive 别解构
  4. computed 和 watch：一个缓存重算，一个变化通知；immediate 和 deep 是 watch 的两个开关
  5. 生命周期加 on 前缀一一对应，created 对应 setup 本身
