Easy File Sharing Web Server 7.2 缓冲区溢出复现

发表于2026-11-08|更新于2026-11-08
|浏览量:

一、实验目的

用 Kali 自带的 searchsploit 查本机 Easy File Sharing Web Server 存在的漏洞，取其中一个公开 Exp，在靶机上执行计算器程序以验证漏洞。

二、测试环境

  • 攻击机：Kali（VMware 虚拟机，NAT 模式）
  • 靶机：Windows 宿主机，192.168.228.1
  • 靶标：Easy File Sharing Web Server 7.2，端口 80

三、实验过程

（1）启动靶标服务

在 Windows 上安装并启动 EFSS，端口保持默认 80，浏览器访问 http://192.168.228.1 确认页面能打开。记得放行 Windows 防火墙对 80 端口的入站，否则后面扫出来全是 closed。

（2）扫描靶机端口

80 和 443 均为 open，服务识别为 Easy File Sharing Web Server httpd 5.5。注意 banner 里的 5.5 是它内嵌 httpd 组件的版本，找 Exp 时按程序本体 7.2 来选。

四、几个注意点

  • NAT 模式下靶机地址要用 VMnet8 的 192.168.228.1，不是 ipconfig 里 WLAN 那张卡的 192.168.3.x。
  • 新版 Kali 默认不带 python2，需要先 apt install python2，否则会报语法错误。
  • 本文实验均在本地虚拟机完成，靶标为自建服务，仅供学习交流。
