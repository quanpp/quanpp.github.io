📑打开知识图谱

一、增删改查（CRUD）的通用套路

做任何管理类页面（图书、商品、用户），本质都是四件事：

操作 HTTP 方法 核心动作
查（Read） GET 拿数据，渲染到页面
增（Create） POST 收集表单 → 提交 → 刷新列表
删（Delete） DELETE 拿到 id → 请求删除 → 刷新列表
改（Update） PUT 回显数据 → 收集修改 → 提交 → 刷新列表

记住一个关键原则：每次增/删/改成功后，都要重新请求一次列表数据来刷新页面。 不要自己手动改 DOM，以服务器返回的最新数据为准。

总结

技能点 一句话
增删改查 查=拿数据渲染；增删改=提交后刷新列表
事件委托 动态生成的元素绑父元素，用 classList.contains 判断
data-id 把数据 id 存自定义属性，删改时取出来
Bootstrap 弹框 直接开关用属性，夹逻辑用 JS
FormData 传文件专用，append 装进去直接传给 axios
localStorage 存 key-value 字符串，刷新不丢
serialize 一键收集表单，返回 JS 对象
