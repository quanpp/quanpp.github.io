Day02 AJAX 综合案例 · 复习图谱

主线：用 axios 完成经典"增删改查"业务 + 图片上传 + 本地缓存

一、增删改查四步法（今天最核心）必须会

查 · 渲染列表
GET 无 method
① axios 获取数据
② map() 拼 HTML
③ innerHTML 插入
封装成函数复用
增 · 新增
POST
① serialize 收表单
② axios 提交
③ getBooksList() 刷新
④ reset() + hide()
删 · 删除
DELETE /:id
① 事件委托找按钮
② dataset.id 拿 id
③ axios 删除该 id
④ getBooksList() 刷新
改 · 编辑
PUT /:id
① 点编辑→查详情回显
② serialize 收表单
③ axios PUT 提交
④ 刷新 + hide()
通用记忆口诀：查=拿数据渲染；增/删/改=告诉服务器改什么 → 成功后重新调用"获取并渲染列表"函数刷新页面。编辑比新增多一步"回显"。

赋给 img.src / 背景
为什么要用 FormData？文件不是普通数字/字符串，必须装进 FormData 以"文件流"形式提交。
头像为什么多带一个 creator？换肤只是存图片地址；头像要存到某个用户名下，所以 FormData 里还要 fd.append('creator', creator)。

四、Bootstrap 弹框：属性 vs JS

  • 属性方式（直接显示/隐藏）：
    按钮加 data-bs-toggle="modal" data-bs-target=".my-box"；关闭加 data-bs-dismiss="modal"。
  • JS 方式（显示前要先跑逻辑）：
    new bootstrap.Modal(dom) → modal.show() / .hide()
  • 什么时候用 JS？点编辑要先把数据填进表单再显示；点保存要先收集数据再隐藏——显示/隐藏前后夹了一段 JS 逻辑就用它。
  • Toast 提示框同理：new bootstrap.Toast(dom).show()，标签上用 data-bs-delay="1500" 控制自动消失。

六、10 道自测题背后的必背技巧

  • 扩展运算符 ...obj 复制对象
  • 事件委托：给父元素绑定，用 e.target + classList.contains() 判断点的是谁（动态生成的元素只能这么绑）
  • 自定义属性：div.dataset.code 读 data-code
  • 类名判断：用 classList.contains('title')，别用 className 全等
  • 伪数组/对象取值：obj[0]，不能 obj.0
  • localStorage：setItem(k,v) 存 / getItem(k) 取（换肤刷新后还在靠它）
  • Object.keys(obj)：得到属性名数组，用来遍历快速给表单回显
  • +数字字符串：+ '10' 转数字；''||'默认' 空串走默认值
回显小技巧（Object.keys 妙用）：当数据对象的属性名和表单标签的 class 名一致时，Object.keys(userObj).forEach(key => querySelector('.'+key).value = userObj[key])，一行循环搞定所有赋值，不用一个个写。
