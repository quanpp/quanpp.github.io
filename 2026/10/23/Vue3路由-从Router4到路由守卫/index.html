Vue3 路由：从 Router 4 到路由守卫

发表于2026-10-23|更新于2026-10-22|技术
|浏览量:

Vue 系列第三篇。前两篇讲的都是”一个页面怎么搭”，这篇解决”多个页面怎么切”：不刷新浏览器的情况下，地址栏变了，内容跟着变。学完你会知道：SPA 和传统多页应用到底差在哪、router-link 自带的那两个类名怎么用、query 和 params 该怎么选、404 的 path: '*' 为什么在 Vue Router 4 里不灵了、history 模式上线为什么要找后端配、路由守卫怎么拦住未登录用户、keep-alive 缓存了组件为什么 onMounted 不再触发。文末附速查表和一份完整的面经项目实战。

一、先说清楚：为什么需要路由

1.1 单页应用是什么

传统网站是这样的：点”关于我们”，浏览器向服务器请求一个新页面，整个页面白屏一下，重新加载。

单页应用（SPA，Single Page Application）只有一个 HTML 文件。点导航时，浏览器不请求新页面，而是由 JS 把当前页面的内容换掉，同时用 history.pushState 改一下地址栏。

多页应用 单页应用
页面切换 请求新 HTML，整页刷新 只换组件，无刷新
首屏速度 快（HTML 小） 慢（要下 JS）
切换速度 慢（每次请求） 快（已加载）
SEO 天然友好 需要 SSR 或预渲染
状态保持 刷新即丢 切换页面不丢

Vue 项目基本都是 SPA。后台管理系统尤其适合——首屏慢一点没关系，操作流畅才重要。

1.2 前端路由在干什么

“路由”这个词在两代技术里意思不同：

  • 后端路由：一个 URL 对应一个接口/页面，服务器收到请求决定返回什么
  • 前端路由：一个 URL 对应一个组件，浏览器里由 JS 决定渲染谁

三条判断经验：

  1. 参数多 → query。?kw=vue&page=1&sort=price 用 params 得写成 /search/vue/1/price，没法看
  2. 参数是”资源标识” → params。详情页 /detail/100 比 /detail?id=100 语义强，也更利于 SEO
  3. 参数可能没有 → query。可选参数在 query 里天然支持（不传就没有），params 要配可选符

5.2 404 兜底

用户输入了一个不存在的地址，不能白屏，要给他一个 404 页：

⚠️ 版本差异：Vue2 时代的 Vue Router 3 写 { path: '*' }，Vue Router 4 里这个写法不灵了，必须写成 /:pathMatch(.*)*。

为什么改？因为 * 在新版路径解析器里有歧义。/:pathMatch(.*)* 的意思是”匹配任意多段路径，捕获进 pathMatch 参数”。见到老教程的 path: '*'，知道对应这个就行。

404 路由必须放最后。 路由是从上往下匹配的，放前面会把所有路径都吃掉。

八、keep-alive：切走再回来，别重新渲染

8.1 问题现场

列表页滚到第 50 条，点进详情，返回——列表回到顶部，数据重新请求，筛选条件丢了。

因为路由切换时，旧组件被销毁了，回来时是全新的组件，onMounted 重新跑一遍。

8.2 解法

用 <keep-alive> 包住出口：

被缓存的组件不会被销毁，只是失活（deactivated），回来时激活（activated）。组件状态、滚动位置都还在。

8.3 三个属性

属性 类型 作用
include 字符串 / 正则 / 数组 只缓存名字匹配的组件
exclude 字符串 / 正则 / 数组 不缓存名字匹配的组件
max 数字 最多缓存几个，超了淘汰最久未用的

⚠️ include 匹配的是组件的 name 选项，不是文件名。<script setup> 里没有 name，得用 defineOptions({ name: 'ListView' }) 显式声明——这就是上一篇讲 defineOptions 的实际用途之一。

8.4 两个专属钩子

典型用法：列表页缓存，但每次回来要刷新数据——在 onActivated 里重新请求。这样既保住了滚动位置，数据又是新的。

总结

路由篇的主干五条：

  1. SPA 的本质是”地址变、组件换、不刷新”，代价是首屏要下 JS，收益是切换流畅、状态不丢
  2. 两个组件管所有跳转：router-view 是出口，router-link 是入口；两级嵌套就是两级 router-view
  3. query 传多个、params 传一个：query 不用改配置、刷新还在；params 语义强、地址好看；path 跳转带不上 params，要用 name
  4. 404 的通配符换了写法：path: '*' 在 Router 4 里失效，改成 /:pathMatch(.*)*，且必须放最后；history 模式上线要找后端配回退
  5. 守卫管”能不能进”，keep-alive 管”回来还在不在”：beforeEach 拦未登录、onActivated 刷新缓存页、include 匹配的是组件 name
