Node.js 入门：从运行环境到模块化与 npm

前端教程系列第五篇。前面我们一直在浏览器里写 JS，这篇跳出浏览器，看看 JS 怎么在电脑上独立运行——Node.js。学完你会知道：怎么用 JS 读写文件、怎么创建一个 Web 服务、怎么用 require/import 组织代码、怎么用 npm 下载别人写好的工具包。

一、什么是 Node.js

Node.js 是一个独立的 JavaScript 运行环境，能脱离浏览器执行 JS 代码。

核心点：

  • 基于 Chrome V8 引擎封装，所以 JS 语法和浏览器里一样
  • 没有 document 和 window（那是浏览器提供的），但支持所有 ES 标准语法
  • 两个用途：① 写后端服务程序；② 做前端工程化工具（压缩、转译、打包）

VSCode 里右键文件 → “在集成终端中打开”，就能快速在当前目录执行。

二、fs 模块：读写文件

fs（File System）是 Node.js 内置模块，用来操作电脑上的文件。

  • .：当前目录
  • ..: 上一级目录
  • 开头/：系统根目录；中间/：文件夹分隔符。

require('fs') 是 CommonJS 语法，后面会详细讲。

三、path 模块：路径处理

3.1 为什么要用绝对路径

Node.js 执行代码时，相对路径是从终端所在文件夹出发解析的，不是从代码文件本身出发。如果你在项目根目录 project-root 执行 node src/index.js，文件操作代码里写 ./test.txt 找的是根目录下的 project-root/test.txt ，不是 src 下的。

解决方案： 用 __dirname + path.join() 拼出绝对路径。

以后在 Node.js 里读写文件，路径一律用 path.join(__dirname, '相对路径')，不会出错。

六、模块化：CommonJS

6.1 为什么需要模块化

Node.js 里每个文件都是独立模块，文件里定义的变量和函数默认是私有的，其他文件访问不到。要共享就得导出（export）和导入（require）。

6.2 导出和导入

内置模块直接写名字（require('fs')），自定义模块写文件路径（require('./utils.js')）。

八、包和 npm

8.1 包是什么

包就是把模块、代码、其他资料整合成的一个文件夹。根目录必须有 package.json 记录包的信息。

两类包：

  • 项目包：写业务代码的文件夹
  • 软件包：封装工具方法供别人使用（如 dayjs、lodash）

导入一个包文件夹时，默认找包里面的 index.js，没有就找 package.json 里 main 指定的文件。
