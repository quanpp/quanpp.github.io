一、函数基础

1.1 定义与调用

  • 形参不需要声明类型，也不需要指定返回值类型
  • 无参数也要保留空括号 ()
  • 函数体必须缩进

1.2 说明文档

函数体第一行的字符串就是文档字符串，可通过 help() 或 __doc__ 查看。

1.3 返回值

  • 无 return 或 return 后无表达式 → 返回 None
  • 多个返回值自动封装为元组

1.4 递归与 __name__

递归：函数自己调用自己，必须有终止条件。Python 默认递归深度约 1000。

if __name__ == '__main__'：脚本直接运行时 __name__ 为 '__main__'，被其他模块导入时为模块名。用于区分”直接运行”和”被导入”。

三、参数传递机制

Python 是值传递——传递的是对象的引用（内存地址），不是对象本身。

结论：需要在函数中修改数据时，把数据封装为列表/字典等可变对象传入。
