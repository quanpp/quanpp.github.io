信息收集实战：从 ZoomEye 到子域名收集

发表于2026-10-22|更新于2026-10-22|技术
|浏览量:

一次信息安全课程作业的完整记录。作业三个问题：除了 ZoomEye，还有哪些功能类似的网络空间搜索引擎？ZoomEye 的搜索语法怎么用，怎么搜？子域名收集有哪些路子？这篇按“搜索引擎横评 → ZoomEye 实战 → 子域名收集”的顺序逐一回答，顺带把被动收集和主动爆破串成一套完整流程。所有检索只搜不碰，目标仅限公开信息和自有实验环境。

一、什么是网络空间搜索引擎

先统一概念。网络空间搜索引擎（也叫网络空间测绘平台）干的事是：持续不断地扫描全网 IP 和域名，把开放端口、跑着的服务、用的组件、挂的证书全部结构化地存下来，建成一个可搜索的索引。

用起来和百度谷歌一样——输入关键词，返回一批“联网的东西”。区别只在搜的对象：

普通搜索引擎 网络空间搜索引擎
搜什么 网页内容 联网设备、服务、组件
数据哪来 爬虫爬网页 扫描器主动探测全网 IP
一条结果 一个网页链接 一个 IP/域名 + 开放端口 + 服务指纹

典型用途四个字：资产测绘。企业用它摸清自己暴露在互联网上的东西（资产暴露面管理），安全人员用它分析漏洞影响面（比如 Log4j 爆发时搜全网受影响资产），红队用它做信息收集，蓝队用它做威胁狩猎。

二、除了 ZoomEye，还有哪些（作业第一问）

ZoomEye（钟馗之眼）是知道创宇的产品，用 Xmap（网络层扫描）+ Wmap（Web 指纹）双引擎，国内资产覆盖好。同类选手一张表看全：

引擎 出品方 特点 适合场景
ZoomEye 知道创宇 双引擎探测，中文界面，国内资产全 国内 Web 资产、组件搜索
FOFA 华顺信安 国内最常用，语法灵活，指纹/证书检索强 企业资产梳理、攻防演练
360 Quake 360 数据量大更新快，支持 ICP/备案信息 资产盘点、态势感知
Hunter 奇安信 威胁情报驱动，企业资产画像 攻击面管理、漏洞预警
Shodan 美国（2009 年，行业鼻祖） 协议覆盖最广，工控/IoT 强 全球设备、工业控制研究
Censys 美国（密歇根大学） 证书/TLS 指纹最强 证书分析、域名关联
BinaryEdge 欧洲 威胁情报向，云资产多 交叉验证、补充数据源

选型建议，直接背：

  • 国内 Web 资产：ZoomEye 或 FOFA，两家对国内站点识别最准
  • 全球设备/工控/IoT：Shodan，老牌选手协议库最全
  • 证书关联、同证书反查：Censys，证书透明度数据玩得最深
  • 别只用一个：严肃的信息收集至少交叉两个引擎，数据盲区各家都有

这些平台都有免费额度（注册账号即可，搜索次数有限制），学习用途免费档基本够用。

三、ZoomEye 搜索实战（作业第二问）

3.1 准备工作

官网 zoomeye.ai，注册登录。界面两种搜索模式，先搞清楚再搜：

  • Host 搜索：搜设备——IP、端口、服务 Banner、协议，偏网络层
  • Web 搜索：搜网站——网页标题、响应体、证书，偏应用层

拿不准搜什么就用默认（全局匹配），它会把 HTTP、SSH、FTP 各种协议的结果一起返回。

3.2 搜索语法

ZoomEye 的语法是关键词 + 过滤器，过滤器用 字段="值" 的形式：

字段 作用 示例
app 应用/组件 app="Apache httpd"
port 端口 port=6379
service 服务协议 service="ssh"
os 操作系统 os="Linux"
device 设备类型 device="camera"
country / city 国家/城市 country="CN"
title 网页标题 title="登录"
domain 域名/子域名 domain="example.com"
ip / cidr IP/网段 cidr="52.2.254.36/24"
ssl 证书内容 ssl="google"
vul.cve CVE 编号 vul.cve="CVE-2021-44228"

逻辑运算符三个：&&（并且）、||（或者）、!=（排除），括号 () 控制优先级。关键词加英文双引号做精确匹配。

⚠️ 版本差异：老教程里大量使用 port:80、app:nginx 这种冒号语法，那是 ZoomEye 旧版写法。现在官网语法是等号形式（port=80），两种都可能遇到，见到冒号写法知道是旧教程就行，照新版写。

3.3 案例一：搜一个组件的分布

想了解某个组件在互联网上的部署情况，比如搜国内跑 Apache httpd 的资产：

结果页三样东西值得看：

  1. 资产列表：每条结果一个 IP，带端口、服务版本、地理位置、Banner
  2. 地图视图：资产的地理分布热力图，一眼看出集中在哪
  3. 点进详情：单个资产的完整指纹——HTTP 头、证书信息、开放端口、组件版本

3.4 案例二：搜一个漏洞的影响面

Log4j2（CVE-2021-44228）爆发时，安全圈的标准动作就是拿 CVE 编号直接搜受影响资产：

返回的全是命中该漏洞特征的资产——这就是漏洞影响面分析。应急响应时排查“我有没有中招”，把自家 IP 段丢进去搜一遍（cidr="你的网段" && vul.cve="..."），比自己扫全网快得多。

⚠️ 搜索归搜索，别手痒去连。搜索引擎返回的资产 99.99% 不属于你，连接、测试、扫描未授权目标都是违法行为。看看就好。

四、子域名收集（作业第三问）

4.1 为什么要收集子域名

主域名（example.com）大家都知道防，但 test.example.com、admin.example.com、vpn.example.com 这些子系统经常被遗忘——它们就是突破口。子域名收集是信息收集的核心一步，目的是把目标的完整资产清单摸出来。

两条技术路线，先记原则：被动收集不碰目标，主动收集会留痕迹。

4.2 被动收集：不惊动任何人的方式

证书透明度（crt.sh）——最推荐的起点。现在网站基本都用 HTTPS，证书里会写着这个证书覆盖哪些域名，一次能带出一大片子域名：

搜索引擎语法——Google/Bing 里搜 site:example.com -www，把 www 排掉，剩下的都是子域名。老办法，但有效。

空间引擎反查——ZoomEye、FOFA、Hunter 都支持按域名查子资产：

证书、标题、IP 归属都能带出关联子域，Hunter 在这方面尤其顺手（它的定位就是企业资产画像）。

在线聚合工具——Virustotal、SecurityTrails、DNSdumpster、站长工具，粘个域名进去直接出列表，适合快速看一眼。

4.3 主动收集：字典爆破

被动收集有个天花板：只能找到“暴露过”的子域。没暴露过的，只能靠字典爆破——拿一份常见子域名字典（test、dev、admin、api、vpn……），挨个拼接成 字典.example.com，逐个做 DNS 查询，能解析出 IP 的就是存在的子域名。

工具链三档，按手感选：

工具 形态 特点
Layer 子域名挖掘机 图形界面 国产，可视化操作，适合入门和演示
subfinder 命令行 Go 写的，快，被动源多，一条命令出结果
OneForAll 命令行 Python，功能全，收集+验证一体

爆破原理和我上一篇《Python 多进程与多线程：从 GIL 到子域名爆破》里手写的那个多线程爆破器一模一样——字典 × 域名拼接 → 多线程 DNS 查询 → 筛出能解析的。工具只是把字典做得更大、并发调得更好。

4.4 完整流程：被动 + 主动组合拳

收集来的子域名一定要用 dig 或 nslookup 验一遍，工具报的子域不一定都解析得通：

⚠️ 授权红线：主动收集（字典爆破、扫描）会对目标 DNS 服务器产生请求量，只对你自己拥有或拿到书面授权的目标做。CTF 练手用官方靶场，别拿真实企业练。

总结

作业三问，三句话收尾：

  1. 同类引擎：ZoomEye、FOFA、Quake、Hunter 四家国内 + Shodan、Censys 两家国际，国内资产用前两家，全球设备用 Shodan，证书关联用 Censys，交叉着用
  2. ZoomEye 搜索：字段="值" 是核心语法，&&/||/!= 组合，搜组件、搜端口、搜 CVE 影响面都是同一套；老教程的冒号语法已过时
  3. 子域名收集：被动（证书 + 搜索引擎 + 空间引擎）先撒网，主动（字典爆破）再补漏，最后 DNS 验证去重，形成资产清单

信息收集是渗透测试的第一步，也是防守方资产梳理的基本功。套路都不难，难的是克制——工具越顺手，越要守住授权这条线。
