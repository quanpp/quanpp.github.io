2.4 Token 是什么

Token 是后端签发的一串字符串，代表”你已经登录了”。

  • axios post请求后且成功 → 后端生成 token 返回给前端（在res里）
  • 前端存到 localStorage，并且改变 location.href 实现跳转
  • 之后每次请求，把 token 带给后端证明身份
  • 后端解密 token 判断你是谁、有没有权限

注意：前端只能判断 token 有没有，不能判断 token 过没过期。 有效性只能后端说了算。token 过期后后端返回 401，前端再处理跳转。

三、axios 拦截器（项目最重要的新知识点）

3.1 为什么需要拦截器

很多接口都需要带 token，不可能每个请求都写一遍 headers。拦截器就是在请求发出去之前统一处理，在响应回来之后统一处理。

3.2 请求拦截器：统一加 token

这样之后你写任何 axios 请求，都不用手动加 headers 了——拦截器自动帮你加。

3.3 响应拦截器：401 处理 + 少包一层 data

两个优化点：

  • 响应拦截器里 return response.data，之后页面里 axios(...).then(res => res.xxx) 直接拿到后端数据，不用 res.data.xxx
  • 401 统一处理，不用每个请求的 .catch 里都判断

拦截器是 axios 本身的功能，原生 JS 和 Vue3 里写法完全一样。

Vue3 帮你省掉的部分

原生 JS 你要手动做 Vue3 自动帮你做
拼 HTML 字符串 + innerHTML 渲染 v-for 自动渲染列表
serialize 收集表单 + name 属性 v-model 双向绑定
编辑时逐个 DOM 赋值回显 reactive 对象直接赋值
动态元素用事件委托 + e.target @click 直接绑
每个页面开头写 token 判断 路由守卫写一次全局生效
location.href 跳转 router.push() 跳转
立即执行函数防全局污染 组件作用域天然隔离

核心结论

先把原生 JS 的业务逻辑想清楚，再学框架会非常快。 框架不教你”怎么和服务器打交道”，它只帮你自动完成了”数据变 → 页面变”这件事。业务逻辑想明白了，换什么框架都是同一个思路。
