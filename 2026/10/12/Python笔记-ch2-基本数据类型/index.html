Python 基本数据类型：从变量到字符串的完整梳理

覆盖变量定义、数字类型、进制转换、字符串操作、输入输出、代码规范、字符编码，以及信息安全专业相关的 hashlib / hmac 模块。

一、变量

1.1 变量定义

Python 变量不需要事先声明类型，直接赋值即可创建。类型属于值（对象），不属于变量——同一个变量可以随时指向不同类型的对象。

Python 采用基于值的内存管理：相同值在内存中只有一份，多个变量指向同一块地址（小整数缓存机制）。

1.2 命名规则

  • 以字母或下划线开头，后面跟字母、数字、下划线
  • 大小写敏感
  • 不能以数字开头，不能有空格和标点
  • 不能使用关键字和内置函数名

专业建议：见名知意，用 grade 而不是 a 表示分数。

1.3 常量

Python 没有真正的常量，约定用全大写字母表示，仅为可读性规范，语法上仍可修改。

二、数字类型

2.1 整数、浮点数、复数

类型 说明 示例
int 整数，无大小上限 3
float 浮点数，必须带小数点 3.0
complex 复数，虚部用 j/J 3+4j

浮点数支持科学计数法：5.21e2 = 521.0（仅浮点型可用）。

2.2 进制转换

  • 二进制：0b 前缀，如 0b101
  • 八进制：0o 前缀，如 0o17
  • 十六进制：0x 前缀，如 0x1A

三、字符串

3.1 表示方式

  • 单引号 '...'、双引号 "..."
  • 三引号 """...""" 支持多行
  • 转义字符 \，换行 \n
  • 原始字符串 r"..."，反斜杠不转义（写路径常用）

3.2 核心特性

  • 不可变序列：不能原地修改，所有”修改”方法都返回新字符串
  • 没有单独的字符类型，单字符也是长度为 1 的字符串
  • 支持索引（正向从 0 开始，反向从 -1 开始）

3.3 常用方法速查

方法 作用 注意
.lower() / .upper() 转小写/大写 返回新串
.title() 每个单词首字母大写
.replace(old, new) 替换 返回新串
.find(sub) 查找子串 找不到返回 -1，不报错
.index(sub) 查找子串 找不到抛 ValueError
字符串.split(sep)，不写sep默认按空白 把字符串按分隔符切分成列表 返回列表
'sep'.join(序列) 把列表/元组用分隔符拼接成字符串 返回字符串
.strip() 去除首尾空白
.startswith() / .endswith() 判断首尾

五、代码规范（PEP 8）

  • 缩进：4 个空格，同层级缩进一致
  • 注释：# 单行，"""...""" 多行
  • 长行：行尾 \ 续行
  • 运算符两侧、逗号后加空格
  • 不同功能块之间加空行

六、字符编码

编码 特点
ASCII 127 个字符，1 字节
GB2312 中文编码，2 字节
Unicode 统一所有语言，2 字节
UTF-8 可变长，英文 1 字节，中文通常 3 字节

Python 3 字符串原生支持多语言，源文件建议保存为 UTF-8。

七、安全专题：hashlib 与 hmac

7.1 hashlib 消息摘要

哈希函数把任意长度数据转为固定长度摘要，用于校验数据完整性。

加盐（Salt）：在原始数据后拼接随机字符串再哈希，大幅增加彩虹表破解难度。

7.2 hmac 消息认证码

比纯哈希多一个密钥，既能校验完整性，又能验证发送方身份。

7.3 雪崩效应

输入改变 1 个 bit，输出约一半 bit 发生变化。MD5 和 AES 都具备此特性，这是密码学算法安全性的基础。
