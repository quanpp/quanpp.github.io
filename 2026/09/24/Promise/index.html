Promise

管理异步操作（请求完毕后再执行下一步），解决回调地狱，

1. 为什么需要 Promise

需求

通过 AJAX 请求 id，再根据 id 请求用户名，再根据用户名获取 email

回调地狱

回调函数中嵌套回调，代码嵌套层级深、难以维护

因为id，username是局部作用域，需要多层嵌套

2. Promise 的基本使用

语法

  • Promise 接受的参数，是函数；返回值是对象实例
  • 传入的函数参数包含两个形参
    • resolve：成功时的回调函数
    • reject：失败时的回调函数

Promise 的对象实例的属性

promise 的对象实例有两个核心属性

  • state：状态
  • result：结果

1) Promise 的三种状态

  • pending：==初始==等待状态，待定
  • fulfilled：成功状态，已完成
  • rejected：失败状态，已拒绝

2) Promise 状态的改变

通过调用resolve()和reject()改变状态

  • resolve ()：将 Promise 状态改为 fulfilled
  • reject ()：将 Promise 状态改为 rejected
  • Promise 状态只能改变一次

3) Promise 的结果

通过 resolve 传递参数，设置 当前Promise的实例对象 的成功结果result

3. Promise 的方法

1) then 方法

示例 1

  • then 的形参value，接收 Promise的resolve()或者reject()传入的实参（结果）

  • then 返回新的 Promise 实例对象，状态是 pending，所以在 then 中使用 return xxx→ ==返回的新的 Promise== 的状态变为 fulfilled，且传出的值是xxx

  • ==Promise 状态不改变，then 内代码不执行==

  • then 中代码报错 → 返回的 Promise 状态变为 rejected

2) catch 方法

使用：在返回的新的promise，然后 .catch()调用方法，传入箭头函数

5. async 和 await

1) async 函数

  1. 函数返回值为 Promise 对象
  2. Promise 结果由 async 函数返回值决定
  3. 类似.then()方法，返回待定状态的promise

示例

2) await 表达式

  1. await 右侧一般为 Promise 对象，也可以是其他值
  2. 右侧是 Promise → await 返回 成功状态的值，失败会抛出错误
  3. 右侧是其他值 → 直接返回该值

注意

  1. await 必须写在 async 函数 中
  2. await 对应的 Promise 失败，会抛出异常，需用 try...catch 捕获

4)promise，async，await结合

==await 用来拿 Promise 里面 resolve 的值，但 await 只能写在 async 函数里面，必须成对用，async相当于摆饰==

axios和promise理解

  1. axios请求放在promise里面，返回的数据用resolve()传递出去
  2. 根据xhr.status判断是成功resolve，还是失败reject
  3. 在promise返回的实例对象.then(value)，获取resolve()成功传的结果
  4. 多次回调需要在.then最后return new Promise()
