AJAX 入门：用 axios 从服务器拿数据

前端教程系列第一篇。如果你一直在写”数据写死在页面上”的静态网页，这篇文章带你迈出第一步——让网页数据活起来。

一、什么是 AJAX

以前我们写网页，数据都是写死在代码里的，想改个内容就得改代码。那能不能像淘宝、知乎那样，数据从服务器实时获取？

这就是 AJAX 干的事：在不刷新整个页面的情况下，用浏览器和服务器通信，拿到数据再局部更新页面。

AJAX 的全称是 Asynchronous JavaScript and XML，它的底层是浏览器提供的 XMLHttpRequest 对象。但我们一般不直接用它，而是用一个更简单的第三方库——axios。

三、认识 URL

URL（统一资源定位符）就是网址，我们要知道它每部分是什么意思：

  • 协议：HTTP，规定了浏览器和服务器之间传数据的格式
  • 域名：标记服务器在互联网上的位置
  • 资源路径：标记这台服务器上你要访问的具体资源

你不需要背，看到一个 URL 能说出”协议 + 域名 + 路径”就够了。

四、查询参数：告诉服务器你想要什么

有时候你不需要全部数据，只要某一部分。比如”查河北省下面的城市”——你得把”河北省”这个条件告诉服务器。

这就是查询参数：在 URL 后面用 ? 拼接，格式是 参数名=值&参数名=值。

五、提交数据：GET 和 POST

5.1 请求方法

除了获取数据，我们还要往服务器存数据（比如注册账号、登录）。这就需要不同的请求方法：

方法 作用 类比
GET 获取数据 去图书馆借书
POST 提交新数据 往图书馆捐书
PUT 更新数据 把书内容改了
DELETE 删除数据 把书从书架拿走

axios 默认就是 GET，不写 method 就是 GET。提交数据要改成 POST。

5.2 用 data 提交数据

axios 会自动把 data 对象转成 JSON 字符串发出去，不用你手动处理。

5.3 axios 核心配置项速查

配置项 作用
url 请求的地址
method 请求方法，默认 GET
params 查询参数，拼到 URL 后面
data 请求体数据，POST/PUT 时提交

七、HTTP 报文：浏览器和服务器说了什么

在 Chrome 开发者工具的 Network（网络）面板里，你可以看到每次请求的完整报文。

7.1 请求报文（浏览器发给服务器）

7.2 响应报文（服务器返回给浏览器）

7.3 状态码

状态码告诉这次请求的结果：

  • 2xx：成功（200~299 都算成功）
  • 4xx：客户端错误（404 找不到资源、401 未登录）
  • 5xx：服务器错误

实用技巧：代码有 bug 时，先打开 Network 面板看看请求到底发出去没有、参数对不对，比逐行读代码快得多。

八、接口文档：后端给的”说明书”

后端工程师会写一份接口文档，告诉你：

  • 请求的 URL 是什么
  • 用什么请求方法
  • 需要传什么参数（参数名、类型、是否必填）
  • 返回的数据结构是什么

前端开发就是照着接口文档写 axios 代码，不需要自己猜 URL 和参数名。

总结

概念 一句话
AJAX 浏览器和服务器局部通信，不刷新页面
axios 封装好的 AJAX 库，语法简单
params 查询参数，拼在 URL 后面，用来”筛选”数据
data 请求体数据，POST/PUT 时提交给服务器
GET / POST 获取数据 / 提交数据
.catch() 捕获请求失败的错误信息
状态码 2xx 请求成功
