一、爬虫基础

1.1 什么是网络爬虫

自动获取网页内容并提取结构化数据的程序。基本流程：

  1. 发送 HTTP 请求获取页面
  2. 解析 HTML / JSON 提取数据
  3. 存储数据（文件 / 数据库）

1.2 robots.txt 协议

爬取前应检查目标网站的 robots.txt，遵守爬取规则：

  • Disallow: /admin 表示禁止爬取 /admin 路径
  • 君子协议，不具备法律强制力，但应遵守

七、爬虫注意事项

  1. 设置 User-Agent：不设置可能被拒绝
  2. 控制请求频率：加 time.sleep()，避免给服务器造成压力
  3. 处理异常：网络不稳定，必须 try/except
  4. 超时设置：timeout 参数防止永久阻塞
  5. Session 复用：保持连接，提高效率
  6. 遵守 robots.txt：尊重网站规则
  7. 编码处理：注意 resp.encoding，中文乱码时设为 utf-8 或 gbk
