Day03 AJAX原理 复习图谱

Day03 AJAX 原理 · 复习图谱

主线：XHR 原生语法 → Promise 管理异步 → 手写 myAxios → 天气预报实战

一、先搞懂：axios 和 XHR 是什么关系

axios = 封装好的工具库，你只传 url / method / params / data 就行
XHR = 浏览器原生提供的对象，是 axios 内部真正干活的人
Promise = 管理异步任务状态的对象，让 XHR 结果能用 .then() 接收
一句话：axios = XHR + Promise + 一堆自动帮你做的事（拼参数、转 JSON、设请求头）

二、原生 XHR 的四步固定流程

1创建对象
new XMLHttpRequest()
→
2配置请求
xhr.open('GET', url)
→
3监听结果
xhr.onloadend = () => {...}
→
4发起请求
xhr.send()
关键区别（和 axios 比，XHR 啥都得自己干）：
• 查询参数：axios 自动把 params 拼到 URL 后面；XHR 要自己拼 ?pname=辽宁&cname=大连
• 提交数据：axios 自动把 data 转 JSON 字符串；XHR 要 JSON.stringify() + setRequestHeader('Content-Type','application/json') + xhr.send(字符串)
• 响应结果：axios 自动解析 JSON；XHR 拿到的是 xhr.response 字符串，要自己 JSON.parse()

三、URLSearchParams：自动拼查询参数

多个查询参数手动拼字符串太麻烦，用它把对象转成 key=value&key=value 格式：

// 把参数对象 → 查询参数字符串
const paramsObj = new URLSearchParams({
  pname: '辽宁省',
  cname: '大连市'
})
const queryString = paramsObj.toString()
// 结果: "pname=辽宁省&cname=大连市"

xhr.open('GET', `http://xxx/api/area?${queryString}`)
这就是 myAxios 里 config.params 那一步内部干的事。

四、Promise 的三种状态（必背）

pending 待定
初始状态，任务正在进行中
fulfilled 已兑现
任务成功完成
触发 .then() 回调
rejected 已拒绝
任务失败
触发 .catch() 回调
死规则：Promise 一旦从 pending 变成 fulfilled 或 rejected，状态就永久凝固，不能再变。
怎么判断请求成功？看 xhr.status 状态码，200~299 之间就是成功，否则失败。

五、手写 myAxios：拆开看 axios 内部干了啥

myAxios 函数做了 4 件事，正好对应你平时用 axios 传的 4 个配置项：

function myAxios(config) {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest()

    // ① params: 有查询参数就用 URLSearchParams 拼到 url 后面
    if (config.params) {
      const qs = new URLSearchParams(config.params).toString()
      config.url += `?${qs}`
    }

    // ② method: 默认 GET
    xhr.open(config.method || 'GET', config.url)

    xhr.addEventListener('loadend', () => {
      // ④ 成功/失败判断：200~299 resolve，否则 reject
      if (xhr.status >= 200 && xhr.status < 300) {
        resolve(JSON.parse(xhr.response))
      } else {
        reject(new Error(xhr.response))
      }
    })

    // ③ data: 有请求体就转 JSON 字符串 + 设请求头 + send
    if (config.data) {
      xhr.setRequestHeader('Content-Type', 'application/json')
      xhr.send(JSON.stringify(config.data))
    } else {
      xhr.send()
    }
  })
}
对照你用 axios 的写法：你传 params → 它帮你拼 URL；传 data → 它帮你转 JSON 并设请求头；传 method → 它默认 GET。返回 Promise → 你就能 .then()/.catch()。

六、天气预报案例：myAxios 的实战

步骤做什么关键代码
默认天气进页面先显示北京getWeather('110100')
搜索城市input 事件实时请求城市列表监听 input，传关键字
点击切换点城市名换天气事件委托 + dataset.code 拿城市编码

七、今天最容易踩的坑

  • 忘了 JSON.parse：XHR 的 xhr.response 是字符串，不 parse 直接用会报错
  • 忘了 setRequestHeader：POST 提交 JSON 时必须告诉服务器"我发的是 JSON"，否则后端收不到
  • send 里传什么：GET 请求 send() 不传参；POST 提交数据 send(字符串)
  • Promise 状态不可逆：resolve 之后再调 reject 没用，状态已经定了
  • loadend vs onload：loadend 不管成功失败都会触发，所以要在里面判断 status；axios 内部也是这么干的
